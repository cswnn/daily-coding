* 지역에서 선언한 정수형 변수를 그 안 지역에서 쓰고 싶을 때는 nonlocal(전역변수를 지역에서 쓸 때 global)
    def solution():
        a = 0

        def solved():
            nonlocal a
            a = 1

* 지역에서 선언한 배열을 그 안 지역에서 쓸 때 요소 값은 바꿀 수 있지만, 동일한 이름을 새로 초기화할 수 없음. 이때도 nonlocal 사용하기
    def solution():
        lst = [1, 2, 3]

        def solved():
            nonlocal lst
            c = i for i in range(10)
            lst = c.copy()

* 놓친 점
    - 라이언-어피치 점수 계산할 때, "score -= 1" 반복시 매번 적용해야 하는데, 반복문 안 조건문에서 a == l인 경우 continue로 건너뛰어서 점수 계산 오류 발생.
    - 끝까지 쏘지 않은 화살이 있을 때는 마지막(0점)에 화살을 전부 털어야 함.
